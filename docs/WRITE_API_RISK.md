# 写入操作风险分级与防御规范 (WRITE_API_RISK.md)

## 1. 风险分级模型 (R0 ~ R4)

| 等级 | 定义 | 典型操作 | UI 防护机制 |
| :--- | :--- | :--- | :--- |
| **R0** | 只读查询 | 查看基站状态、读取短信列表、查看电量 | 无阻碍直接执行，自动周期性轮询 |
| **R1** | 低危写入 | 发送短信、删除短信、切换 SIM 卡、修改短信转发配置 | 普通确认对话框，即时执行 |
| **R2** | 服务中断 | 保存 2.4G/5G Wi-Fi、修改局域网网关/DHCP、锁定小区频点 | 醒目标注“将短暂断网”，提示服务重启耗时 |
| **R3** | 系统重启 | 触发路由器软重启 (`/sbin/reboot`)、修改管理员密码 | 红色警告对话框，强制 **3 秒倒计时** 方可点击确认 |
| **R4** | 永久改写 | 改写 IMEI 串号、向基带发送裸 AT 指令、清空 NVRAM | 血红色危险警报，强力提示可能变砖，强制 **3 秒倒计时** 与文字核验 |

---

## 2. 自动化审计与测试安全约束
在开发与自动化测试期间：
- **只允许针对真机测试 R0 只读接口**。
- **严禁向真机自动发送 R1 ~ R4 写入请求**（如批量发短信、锁定不存在的小区、重启设备、改写 IMEI）。
- 所有 R1 ~ R4 写入逻辑与表单构建器的测试，必须严格通过本地单元测试（`MockWebServer` 与离线验证器）完成。
