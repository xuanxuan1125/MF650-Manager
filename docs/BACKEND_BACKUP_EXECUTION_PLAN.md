# 当前后台只读备份：条件方案

2026-10-02。状态：**CONDITIONAL_DRAFT / NOT_READY / NOT_EXECUTED**。

备份 BAT 的读取意图为 ADB pull `/www`，但随包客户端可信度、当前 transport/权限、当前 8081 程序路径及导出覆盖未确认。此文供审阅，不是执行批准，也不是已验证可用入口；不创建新的执行阶段、不接触设备、不运行原工具。

| 可信主机客户端 | 随包 adb.exe 未完成可信度验证 | 使用来源/hash 可验证的客户端；不执行三个附件内 exe/BAT/其他代码 |

| 8081 运行身份 | PID/path/hash/启动方式 UNKNOWN | 从已获得的受支持只读导出取得实际监听进程、执行文件、配置和工作目录；本轮不发 shell 命令 |
| 完整备份范围 | 仅已知 `/www`；后端覆盖 UNKNOWN | 用实际路径确定 daemon、路由资源、依赖/配置、service；不能把 `/www` 读成功自动称为完整后台备份 |
| 用户授权 | 仅本轮离线分析授权 | 上述范围具体且可审阅后，用户明确确认独立的只读执行阶段 |

保留旧页面 hash、已采集版本标签 v5.2.4、本次附件 hash 和基线提交。实际执行阶段仍须核对当前设备状态，不能把历史缓存当成执行时基线；请求应限于已证实无副作用的读接口，具体清单待入口证据明确，不重新调用更新或控制接口。

## 拟议读取及本机输出

目前唯一从 BAT 提取的读请求是 **ADB SYNC pull `/www`**；没有 HTTP POST、shell、AT、RPC 或设备打包。`/usr/bin`、`/home/root`、`/data` 等参考包路径**不是获准整目录读取范围**，待真实进程路径确定后只列必要文件。

输出到新的本机 `test-results/backend-backup/<run-id>/`，避免覆盖既有备份。本机生成文件字节数、SHA256、来源路径、读取时间、完整性/缺失标记；可读取的属主/权限/软链接和服务配置应记录，不能伪造缺失元数据。涉及 IMEI/ICCID/MAC/序列号/令牌/配置凭据的原件全部留本机忽略目录，只提交脱敏分析和 hash。

预期结果是“实际读取范围与缺失范围”清单；只有文件与当前进程身份、版本/页面形成足够强的关系后，才能判断当前后台导出完成，并开展 `/api/device/info → handler → 数据 → 公式 → JSON` 离线逆向。目录复制成功本身不满足该成功条件。

## 写入影响和停止点

设备意图写入：**0**；本机写入：备份目录和分析元数据。主机 ADB server、密钥/授权等行为仍需可信客户端和既有授权证据，不自动触发或接受新授权流程。

以下任一情况立即停止：连接关闭/认证或权限失败；目标不唯一；读取路径与当前进程不符；需要 root、上传、改 USB/服务/权限；需要执行任何未知脚本；后端范围无法确认；返回不完整且无法通过已有只读证据核验。保留本机错误/部分结果，不安装补丁、不重启设备、不自动尝试其他端口。

当前方案**不需要临时 tar**。若以后必须在设备创建 tar/marker/cache，改标记 `REQUIRES_TEMP_WRITE`，停止方案执行并提交具体路径、内容、清理与影响供用户另行明确确认；时间经过或“继续离线分析”不视为该确认。没有预设 rm 清理命令。

## 恢复与执行状态

计划不改变设备文件/服务，因此没有设备恢复命令。失败仅保留本机部分备份供核验，不删除设备对象。若无法确保只读入口，方案保持 NOT_READY。此备份完成前也不能声称具备以后部署的可恢复原件；后续 RAM 部署须独立确认原件 hash、权限、配置、恢复入口与授权。
