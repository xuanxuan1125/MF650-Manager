# MF650 Manager 界面设计规范与交互逻辑 (UI_DESIGN.md)

## 1. 视觉设计理念

- **现代硬核科技感 (Cyberpunk Router Aesthetics)**：
  - 采用深灰微透明亚克力质感（Dark Surface Variant + GlassCard）。
  - 主品牌色采用高饱和科技青（`#00E5FF`），辅以品红（`#FF4081`）呈现极速上行，翠绿（`#00E676`）指示强蜂窝信号。
- **阶梯式风险色彩语汇**：
  - **R0 只读**: 翠绿色 (`#4CAF50`)
  - **R1 常规低危**: 天蓝色 (`#03A9F4`)
  - **R2 服务重启/配置修改**: 暖橙色 (`#FF9800`)
  - **R3 系统重启/离线**: 亮红色 (`#F44336`)
  - **R4 硬件与底层改写**: 暗血红 (`#D50000`)

---

## 2. 核心交互流程

### 2.1 状态轮询与离线优雅降级
- 顶层悬浮 `OfflineBanner` 在路由器断开连接时平滑滑入，显示“无法连接至路由器 (192.168.100.1)，正在尝试重连...”，绝不弹出阻塞全屏的报错弹窗。
- 数据刷新采用增量更新，界面不闪烁，图表持续平滑推进。

### 2.2 小区与频段锁定交互
1. 用户在 `CellularScreen` 点击“锁定 LTE”或“锁定 5G NR”。
2. 弹出 `RiskConfirmDialog`，标明 R2 风险评级。
3. 用户输入 ARFCN 频点与 PCI 小区号并确认。
4. 下发后立即触发基站状态重新查询，成功后更新主服务小区指标卡片。

### 2.3 Wi-Fi 重启倒计时交互
1. 用户修改 2.4G 或 5G SSID / 密码并点击保存。
2. 弹出 `RiskConfirmDialog` 提示将重启无线驱动。
3. 用户确认后，界面顶部滑出进度指示条，开始 15 秒倒计时，倒计时结束后刷新连接状态。
