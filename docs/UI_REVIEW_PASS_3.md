# UI 走查审计报告 - Pass 3: 数据正确性、单位体系与离线优雅降级

## 1. 走查目标与范围
- **目标**：验证“电池电量 150%”等严重数据展示 BUG 是否从根源上被消灭，审查网络波动下的容错降级。
- **范围**：`BatteryNormalizer`、`UnitNormalizer`、`BackendHealthBadge`、双后台探测与图表数据流。

## 2. 检查项与审计记录

| 检查维度 | 预期设计标准 | 审查结果 | 状态 |
| :--- | :--- | :--- | :--- |
| **电量正确性 (Zero Clamp)** | 严禁通过 `clamp(0, 100)` 掩盖真实硬件映射；必须精准对应 `charge.html` 0..6 离散阶梯 | 通过 `BatteryNormalizer` 实现 0..6 到 `[0, 10, 25, 50, 75, 90, 100]%` 映射，彻底根除 150% 错误 | ✅ PASS |
| **速率单位统一** | 解决 8081 `0.26` (MB/s) 与 Port 80 字节流单位混淆；60 秒折线图平滑滚动 | `UnitNormalizer.parseSpeedToKb` 自动判断无量纲小数乘以 1024，折线图维持 60 个采样点双轨平滑呈现 | ✅ PASS |
| **信号指标量化** | RSRP (dBm)、SINR (dB)、RSRQ (dB) 进行物理有效值区间校验 (-140..-40) | 非法或空值时显示 `--`，严禁抛出 NullPointerException 或 NaN | ✅ PASS |
| **双后台解耦离线处理** | 当 8081 离线但 Port 80 在线时，基础网络与电量降级展示，高级按钮置灰提示 | `BackendHealthBadge` 三指示灯独立判定，高级入口显式标注“8081 离线”，无闪退 | ✅ PASS |
| **列表空状态展现** | 短信收发件箱为空或无数据时，展示半透明矢量图标与友好文案提示 | `MessagesScreen` 与 `CronSubScreen` 均提供标准 Empty View 引导 | ✅ PASS |

## 3. 走查结论
第三轮走查确认：**核心数据流已建立严格数学与物理量化转换契约，彻底消除了历史版本的离奇数值与假死隐患**。
