# 轮询策略与性能优化规范 (POLLING_AND_PERFORMANCE.md)

## 1. 双端口接口性能基准测试回顾

在第二阶段真机审计中，针对 `192.168.100.1` 实测响应耗时如下：
- **Port 80 `/system_status_data.asp`**: 平均耗时 **6.89 ms**（C 原生嵌入式 HTTP 服务器直接读取 `/proc/stat` 与内存，极快且几乎不消耗 CPU）。
- **Port 8081 `/api/device/info`**: 平均耗时 **1383 ms**（Go 脚本执行了多个系统外部 shell 命令与 AT 指令查询，耗时极高且会短暂抢占基带队列）。
- **Port 8081 `/api/cell?ACTION=get_status`**: 平均耗时 **120 ms**。
- **Port 8081 `/api/liuliang?traffic-usage`**: 平均耗时 **45 ms**。

## 2. 分级轮询调度策略

为了在保证秒级刷新体验的同时，绝不拖垮路由器弱鸡的 CPU 和基带，App 实现了精细的四级分频轮询：

| 级别 | 周期 | 目标接口 | 采集数据 | 目的与考量 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 极速** | **2 秒** | Port 80 `/system_status_data.asp` | CPU、内存、电池格数、未读短信、4G/5G RSRP | 6.89ms 极速响应，实时察觉网络波动与短信到达 |
| **L1 流量** | **2 秒** | Port 8081 `/api/liuliang?traffic-usage` | 上下行实时速率、累计已用流量 | 驱动原生 Canvas 折线图，呈现流畅的网速起伏 |
| **L2 电池** | **6 秒** | Port 8081 `/api/device-status` | 库仑计精确电量、直供电状态、电压与温度 | 监控 IP5332 PMIC 硬件温升与充放电安全 |
| **L3 概览** | **10 秒** | Port 8081 `/api/device/info` | 固件版本、IMEI、MAC、连接设备数 | 低频采集静态信息，彻底避免 1383ms 接口的高并发压迫 |

## 3. 内存与电池续航优化
1. **协程生命周期感知**：轮询任务绑定在 `viewModelScope` 中，当 Activity 退至后台或屏幕关闭时，协程自动挂起暂停网络请求，杜绝后台偷跑电量。
2. **滚动数据环形队列**：网速历史仅维护固定容量（20 点）的轻量级数组，防止内存泄漏。
3. **OkHttpClient 连接池复用**：双端口共享 HTTP Keep-Alive 连接池，单次轮询零 TCP 三次握手开销。
