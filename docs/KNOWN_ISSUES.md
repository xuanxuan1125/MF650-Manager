# 已知限制与固件特性说明 (KNOWN_ISSUES.md)

1. **Port 8081 `/api/device/info` 接口耗时较长**
   - **表现**：该接口在设备负载高时响应耗时可达 1.3 ~ 1.5 秒。
   - **原因**：固件后台 Go 进程在处理该请求时同步执行了多项系统命令。
   - **规避方案**：App 对其设定了 10 秒低频轮询，且绝不在主界面高频触发。

2. **Wi-Fi 变更时网络必定中断约 15 秒**
   - **表现**：下发 2.4G 或 5G Wi-Fi 配置后，手机会出现短时间 Wi-Fi 断开或切换至蜂窝数据。
   - **原因**：Padavan 固件需要执行 `/sbin/restart_wifis` 重新加载驱动内核模块。
   - **App 应对**：App 界面提供精确倒计时进度条，倒计时完毕前抑制重连报错弹窗。

3. **IMEI 修改后必须重启设备生效**
   - **表现**：写入新 IMEI 后，基带必须热重启或整机重启才能让 SDX55 重新向基站报告新串号。
   - **风险提示**：频繁修改 IMEI 可能触发运营商风控导致锁卡，属于 R4 极高危操作。

4. **Port 7689 ttyd 终端需要键盘交互**
   - **表现**：在部分小屏手机上弹出软键盘可能挤压终端字符高度。
   - **应对**：已在 `AndroidManifest.xml` 中配置 `windowSoftInputMode="adjustResize"`，适配终端视窗自动伸缩。
